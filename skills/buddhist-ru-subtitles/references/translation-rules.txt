中文到俄语翻译规则
适用范围：佛教、藏传佛教及密宗相关字幕翻译。

一、藏语人名的俄语转写

1. 本套默认配置采用统一的实用音写。涉及藏语音节末的 g、b，在核实姓名及音节结构后，分别采用 к、п；拉丁音写中的 ö 统一写作 ё。这里说的是音节末，不只是整个姓名的词尾。

2. 本套默认配置采用以下固定写法：
   Dragpa / Drakpa → Дракпа
   Dragden / Drakden → Дракден
   Lhundrub / Lhundrup → Лхундруп
   Lodrö → Лодрё
   Dromtön → Дромтён
   Dudjom / Düdjom → Дуджом；本套默认配置不采用 Дюджом。
   Serthar / Sertar（色达）→ Сертхар；本套默认配置不采用 Сертар。
   Tingri / Dingri（定日、当热）→ Тингри；本套默认配置不采用 Дингри。
   原名为 Dromtönpa 时保留完整形式 Дромтёнпа，不因上述例子擅自删去 pa。

3. 不机械替换姓名中的所有 g/b 或 г/б，不把 ng 当作词尾 g，也不把梵语人名套入藏语音写规则。优先核实藏文、可靠音写和人物身份；不能只凭汉字读音、法语拼写或字母替换推断姓名。

4. 同一人物在同一项目中保持一致。遇到 Драгпа / Дракпа、Лхундруб / Лхундруп 等异写时，按本套默认配置已确定的形式统一。上述选择属于项目转写约定，不据此宣称其他学术或出版转写体系一律错误。

   敦珠统一写作 Дуджом，色达统一写作 Сертхар。变格时以所选规范形式为词干，按俄语语法正常变化，不把变格形式误当作另一套拼写。

5. 如果已确认的术语库条目与本规则冲突，应先核对并确定当前任务采用的规范写法（仅记录选择，未获授权不改词库文件），再在后续字幕中一致采用；不要在不同字幕中轮流使用两个拼法。

6. 不得把不同藏文原词当作同一词的异写来统一。特别区分：
   Chetsün（藏文 lce btsun）→ Чецун；用于 Чецун Сенге Вангчук 及 «Чецун Ньингтиг» 等专名。
   Jetsün（藏文 rje btsun）→ Джецун；通常是“至尊、尊者”等敬称。
   Чецун 不得一律改为 Джецун。中文“杰珍”等音写可能混用，须依据对应人物、法系或藏文原词判断。

7. 蒋扬、仓央在已确定姓名中分别采用 Джамьянг、Цангьянг，保留软音符号 ь；不把这一约定机械推广到所有含“扬”的姓名。

二、头衔的信息保留

1. 原文明确出现的比丘、译师、国师等身份或头衔必须保留，不得为了缩短字幕而只留下人名。应在保留信息的前提下调整俄语语序。

2. 比丘采用 бхикшу；译师采用 лоцава。国师等涉及历史制度的头衔，应核实其具体身份后采用相应的俄语称谓，不能无依据地把国师、帝师、一般教师相互替换。

3. 不添加原文没有的头衔或身份，不因为同一人物在别处被称为仁波切、堪布、国师等，就在当前字幕中自行补上这些称谓。

4. 本套示例中的“格西格沃西尼”“卡绕瓦尊者”“帝察活佛”将称号与人名分开入库：格西：геше，格沃西尼：Гево Сини；尊者：досточтимый，卡绕瓦：Карьова；活佛：тулку，帝察：Дича。已有称号词条复用，不重复添加。翻译完整称呼时仍须同时保留称号和人名，按俄语语序、句法和句首大小写组合，不能直接照搬中文排列顺序。此项拆分不代表其余复合词条均需自动拆分。

三、头衔和泛称的大小写

1. 转轮王这类泛称采用小写，如 чакравартин；不因其出现在佛教文本中就自动大写。术语表中的普通词头也不因独立成行而自动大写。

2. царь 表示世俗君主头衔时采用小写，如 царь Прасенаджит。人名本身仍按专名规则大写。

3. 句首依俄语规则大写。正式全称、正式尊称、固定宗教称号或书名有特殊写法时，按已确认的俄语规范处理。不能把“царь 通常小写”理解成这个词在任何位置都不得大写，也不能把所有宗教头衔一律大写。

4. 按本套默认字幕约定，尊称及宗教专名中的 Будда、Бодхисаттва、Досточтимый、Дхарма、Сангха 采用大写，变格后保留大写。普通称呼 тулку、лоцава 采用小写，句首正常大写。术语库中独立词头“尊者：досточтимый”用于字幕尊称时采用 Досточтимый，不因其独立词头小写而丢失本项字幕约定。геше 沿用词库的普通称呼写法，句首大写。

四、选择与交付

1. 比较两个字幕译句时，先确认语义、人物身份和信息完整，再依据本规则检查姓名转写、头衔及大小写。符合转写规则是选择依据之一，不能代替整句的准确性判断。

2. 最终字幕只输出译文，不夹带姓名转写依据、异写比较、大小写解释或其他校核批注。本规则及相关核对资料单独保存，不并入术语译文或字幕正文。

五、术语表的编码与格式

本套默认配置的中俄术语表统一采用以下格式。之后制作、修订术语表以及依据术语表翻译字幕时，均遵循本规范；本节属于规则文件，不加入术语表的俄文译项。

1. 编码统一为 UTF-8 带 BOM，与参考俄语术语库一致。

2. 每个词条独占一行，中俄两栏以全角冒号“：”分隔，冒号前后均无空格、无 Tab。格式为“中文词条：俄文译名”。中文原词内部的冒号不作为中俄分隔符；应先辨认两栏，再分别规范标点。

3. 中文多名之间统一使用“/”，左右不加空格。相邻的两个书名之间补“/”，例如“《当日教言》/《修行百颂》”；不得写成“《当日教言》《修行百颂》”。

4. 俄文多个译名之间统一使用半角分号加一个空格“; ”，不用斜杠或中文分号。例如“Гуру Падмасамбхава; Гуру Ринпоче”。格式调整不用于增加、删减或重新选择译名。

5. 俄文解释性破折号统一使用长破折号“—”，左右各一个普通空格。姓名、复合词和梵语音译中的连字符“-”按词形保留，不机械改成破折号。

6. 俄文书名外层使用“«»”，内层使用““””，例如“«Комментарий к “Украшению мадхьямаки”»”。书名号和引号内侧不加空格。

7. 俄文译项内部的说明冒号使用半角冒号，冒号前无空格，后面一个普通空格“: ”。例如“Практика Ваджрасаттвы: медитация”。不得把俄文内部冒号改成中俄分隔用的全角冒号。

8. 去掉行首、行尾空格；不间断空格替换为普通空格；Tab 和连续空格清理为正常格式。词语之间需要的空格保留，但不得出现双空格。中俄分隔符和中文多名分隔符两侧仍按上述规则不留空格。

9. 中文兼容字形和部首字形恢复为常用汉字，尤其统一为“月、生、行、心、门、山”。例如“⽉”改为“月”、“⽣”改为“生”、“⾏”改为“行”、“⼼”改为“心”、“⾨”改为“门”、“⼭”改为“山”。这项处理用于字形规范化，不扩大为其他词语的改写。

10. 保存后检查编码、分隔符、空白、引号层级、兼容字形及词条数量；确认仅改变格式，没有改变词条内容、译名含义和排列顺序。

11. 翻译字幕时，以这份格式统一的术语表作为术语依据；存在多个译名时，为当前语境选用合适译名，最终字幕只输出对应译文。
