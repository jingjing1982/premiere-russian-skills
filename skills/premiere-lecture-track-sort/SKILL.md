# 讲座观众与翻译分轨

## 用户使用说明

- **什么时候用**：讲座、问答需要把听讲观众和口译片段分到不同视频轨。没有翻译时只挑观众；不限俄语，但必须具备对应语言的声音判断能力。
- **需要准备什么**：指定工程和序列，媒体在线，提供最新已保存内容或可核实的内存状态。本机需可用的Premiere控制连接；无需先做示范。首次由助手检查依赖及连接，安装技能不会自动安装桥梁或取得权限。
- **一句调用示例**：`$premiere-lecture-track-sort 处理当前工程的“演讲”和“问答”全片，没有翻译，只把听讲观众视频移V2；在独立预览中保留已有切分、音频位置与链接、字幕和标记，核验保存后交付。`
- **完成后检查什么**：打开交付预览，复核分类表中的镜头与疑点。V2可能伴随讲者或翻译声音，不能当作删除清单；保留链接时删除视频也可能选中音频。后续剪辑由用户处理。

## 任务边界和默认值

只做识别、必要的同步切分、视频移轨、核验和保存独立预览。不复制时间线片段，不改变时长、字幕、标记、音量、速度、效果或音频轨道，不删除翻译、整理停顿或生成字幕。用户仅要求检查/改技能时不连接PR。

默认值见 [assets/defaults.json](assets/defaults.json)：观众V2、其余翻译V3、每批20个动作、抽帧并行2个、思考起音保留。批量大小和抽帧并行数可在任务中调整并写入记录。内置执行器目标轨道限定V2/V3，不把修改JSON当作任意目标轨道支持；变更轨道需另行验证工具。无可靠自动角色推断默认：模式由本次需求确定，不清楚有无翻译时先查看媒体，仍不明确再询问。

共同约束：音画范围不重漏、音频原轨原位、真实链接保持、来源不覆盖。不导入作者的历史许可、绝对路径或特定工程身份；当次授权足够时直接继续，不重复索取相同确认。实际接口拒绝时停止该请求，核对可用能力及具体缺项，不改走旁路或自动扩大权限。需要新的安装/权限变更时依当前用户授权处理。

## 助手执行流程

1. 读 [连接与兼容性](references/connection.md)，运行 `scripts/preflight.py`；只读确认完整工程路径、序列UID、timebase、最新状态及媒体。给每个序列单独任务目录和预览；禁止凭同名序列猜测。无需界面操作时不用UI。
2. 用 `scripts/task_setup.py inspect` 枚举已保存序列；核实最新保存状态后 `prepare` 创建字节一致的来源快照和独立预览。该工具不打开PR、不保存主工程。未保存内容必须先取得可靠最新版本，不能冒充已读取；用户确认保存后立即继续。
3. 读 [识别规则](references/recognition.md)。只挑观众时跳过全片转写；逐片段首轮画面筛查，再对候选检查首中尾与内部变化。有翻译时结合实际声音、画面、角色和上下文；外语或字幕空白本身不等于翻译。观众优先V2，观众同期为翻译不另复制到V3。思考性起音保留，不自动列为翻译。
4. 按 [操作与数据格式](references/operation.md) 完成全片 `review.json`、`config.json`。分类包含保留及不确定范围，每次新切点留证据。使用缓存和联系表提速，但未知/混合镜头不能单凭中间一帧下结论。资料缺失不编造证据，明确部分先完成。
5. 使用 [批量执行工具](references/tools.md) 生成受限清单。核对预览UID、轨道可用及媒体在线。首个实际必要动作及首次必要切分保存核验后连续批量执行；纯移轨不得为测试额外切一刀。每步局部核验，每批、恢复及最终全量保存核验。断线先查实际已完成前缀，不盲目重做。
6. 依 [交付检查](references/delivery.md) 交付预览、序列身份、已实施数量、逐项分类/保留清单、核验和耗时。没有原生执行成功仅能称“分析/清单准备完成”；结构核验、机器声音分析和实际听审分别报告。到此结束，不接续人工剪辑阶段。

运行脚本的目录均相对于本技能文件夹；任务文件使用当前用户实际路径，由助手填写。脚本不内置识别模型，也不能证明语义分类正确；分类必须由具备实际图像/音频能力的助手完成。安装与离线测试不等于实机PR验收。

## 任务收尾

开始与交付前遵循[任务目录、预览和收尾](references/task-lifecycle.md)。不重复创建备份、预览或依赖环境；不清理用户已有工程和素材。
