# 首次连接与支持范围

Python 3.11+；联系表使用requirements.txt中的Pillow，媒体抽帧需要ffmpeg，媒体检查可用ffprobe。Node.js只用于离线JavaScript模拟测试。`preflight.py`只报告，不安装、不启动PR。

内置原生执行器面向Windows，使用CEP/ExtendScript和QE；要求本机已有经用户授权的连接，提供能执行限定脚本的能力。技能不是PR插件。面板“已连接”只证明通信，不能证明支持移轨、切分或保存。不要假定不同名称的桥梁具有同样接口。优先发现已安装的专用连接，调用只读状态；具体连接启动按该环境说明，不携带作者的端口、令牌、签名、白名单或安装目录。

批量运行器接受本机Python适配器文件，函数 `run_pr_script(script: str)` 返回JSON字符串或对象；错误必须抛出异常或返回 `{"error":"原因"}`，不能只返回“已提交”。优先复用已有适配器；只有接口和返回约定已有文档依据时才编写薄封装。不猜测HTTP端点或把任意MCP工具当成已适配。不具备此接口时仍可完成离线识别，不能称为已执行；说明确切的连接缺项后对接支持的工具。无需用户手改技能代码。

新环境实际检查：读取PR版本、工程路径、目标UID、帧率、媒体在线、轨道数量与锁定状态；在预览核实DOM与QE活动序列一致。身份字段缺失或不符停止，不移除保护以求成功。连接准备不保存、关闭、重启PR；只有连接确实失败才让用户完成最小必要步骤。

内置队列支持25/50整数fps、标准文件媒体、1倍正向速度、一视频对应一音频链接、帧对齐时间、无叠层/复杂音频重叠。字幕可存在并保持。源时间与序列时间必须分别记录。转场、嵌套、多机位、变速、多声道拆分、非帧对齐音频、未知保存结构不自动简化。整序列无法通过结构检查时，内置队列不能运行；仍交付已确认分类及明确不支持结构，不宣称只跳过复杂片段后全片已执行。

V2必须存在；有翻译动作才需要V3。缺失轨道时先报告缺项。若当前已验证原生连接支持安全增加空轨，可在独立预览添加必要空轨，保留最初来源快照，保存新的执行基线，并重新建立与该基线匹配的分类及清单；额外轨道变化单独核验和交付。内置工具不会猜测添加轨道的接口，也不在主工程补轨。执行基线与来源差异只可包含已记录的必要空轨；其它变化停止。

公开版本的离线测试覆盖受测计划、保存图审计、分类门禁和模拟断点恢复。原自用方法有Premiere2026下50fps切分/移轨与25fps移轨经验；不能将这些经验宣称为公开封装已在新电脑实测。25fps切分及任何新PR版本必须先验证首个实际需要的动作；无切分任务只验证移轨。
