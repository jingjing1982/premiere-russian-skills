# 先测本片气口，再定接缝

本参考用于真正执行剪辑时。字幕只给出候选空白；句末真实气口、换人余量和可删声音范围要从**当前成片的最终音轨**判定。剪前先运行 `scripts/pause_probe.py` 做机器参考，再看/听疑点。脚本不连接或修改 PR。

## 输入与运行

从已核实的最新目标序列提取一个 JSON。时间一律为**整数序列帧**，`source_in_seconds` 为该音频片段首帧在媒体中的入点秒数。音频行按时间线顺序排列，不能重叠；仅支持正向 1 倍速、单条最终有效音轨。轨道叠加、变速、效果或音量自动化会使源媒体分析不代表最终听到的声音，此时先得到与当前序列一致的最终音频参考，或只做人工听审并注明限制。不要为了跑脚本而改变原工程。

```json
{
  "fps": 50,
  "analysis_threshold_dbfs": -35,
  "audio_rows": [
    {"start_frame": 0, "end_frame": 5000, "source_in_seconds": 0.0, "path": "D:/media/part1.mp4"}
  ],
  "cues": [
    {"start_frame": 50, "end_frame": 120, "speaker": "speaker_A", "sentence_end": true},
    {"start_frame": 135, "end_frame": 190, "speaker": "speaker_A", "sentence_end": false}
  ],
  "candidates": [{"id": "gap-1", "start_frame": 120, "end_frame": 135}],
  "cuts": [{"id": "cut-1", "start_frame": 124, "end_frame": 130}]
}
```

`cues` 和 `audio_rows` 必填。`speaker`、`sentence_end` 应依据字幕、画面和声音核实；未知说话人留空，不能猜成同一人。`candidates` 可在计划阶段提供，`cuts` 只在明确拟删范围后提供。先执行：

```text
python scripts/pause_probe.py 输入.json 测量结果.json --cache-dir 本任务临时缓存
```

需要 `ffmpeg`、`ffprobe` 可执行文件。媒体身份包含绝对路径、大小、修改时间、采样率和声道数；相同媒体与阈值复用缓存。缓存只放本任务临时目录，结束时按任务清单清理。此工具不依赖固定本机路径、旧工程 UID、历史桥梁权限或特定帧率。

## 如何读结果

- `reference_by_speaker_and_kind` 分说话人列出句末与其他停顿的样本数、中位数、四分位数；`sentence_end_all_speakers` 是全序列兜底。样本太少、说话人未知或原字幕分句不准时，抽样听审并在报告标注，不能把合并统计冒充某人气口。
- 正常句末停顿可从**当前人句末分布**的中位数至上四分位数选参考；换人时取相邻讲话人的句末参考，加少量有证据的交接余量。不能把两侧各加一份，不能只要求字幕外空白等于某个秒数。尤其要把字幕内部原有静默算进前一句实际末音到后一句实际起音的**总气口**。
- `candidates` 中的低能量区间仅用于找可复核范围。默认 `-35 dBFS` 是检测参数，不是可剪判定；底噪、呼吸、弱起音、笑声和掌声需结合画面/声音确认。气口分布也只是机器参考，不是听感合格证。
- `cuts[].all_channels_exact_zero` 为真，表示该**拟删范围**在源媒体原采样率、所有声道解码后没有非零数字采样；为假或音频覆盖不全时，不得称为静音剪切。脚本检查源音频，不能证明 PR 音量/效果处理后的最终混音，也不能证明画面接缝自然。

## 精确执行与交付

每处先确认末音、尾音/呼吸和下一句弱起音，再决定切点；句末正常范围只是目标，必要问答交接、标题、片头片尾叙事另列保护。已确认连续多余的中间镜头若位于声音安全范围，连同其短残留一起处理。切单必须采用整数帧，并跑 `frame_plan.py` 与 `seam_audit.py`；只在独立预览中原生提取，保存后重读工程全量核验字幕、音画源帧、链接和效果。

接缝表至少给出：原字幕空白、剪前/剪后**总声音停顿**、该说话人句末参考、删除帧区间、新接缝帧时码、两侧保留内容、例外及听审范围。若只能证明数字静音与结构正确，明确写“未逐处实际听审”；不能写“声音自然已通过”。
