# 任务目录、预览和收尾

适用于本技能产生的文件及应用操作，不授权清理用户已有工作。

- 开始先核实来源完整路径、版本/摘要、目标序列UID及未保存状态；涉及应用时记录用户原先打开的工程和活动对象。已保存备份不代表包含内存修改。
- 先查当前任务的有效进度、备份和缓存。一个任务沿用一个目录，明确交付、必要恢复来源、临时文件；中断或重连不新建整套副本或重复安装环境。
- 同一来源版本只保留一份已核实可恢复的备份，可复用匹配摘要的现存备份。独立预览引用原媒体，不复制大视频/音频；首处和批末检查代替每小步复制整个工程。
- 默认一次只额外打开一份预览；核验下一份前关闭自己已用完、确认没有用户后续修改的工程。同一来源的演讲/问答可以在一份预览中使用明确命名的序列，但不为凑数量跨版本混合来源。
- 文件名、序列名须区分项目、用途和版本；同名旧稿与新稿不同时留在应用里。交付只链接当前有效版本，说明是否已实际在PR打开及核验范围。
- 保留用户原有工程和未保存工作；不为整理而保存、丢弃或重启应用。结束时恢复用户工作对象或停在明确的交付序列，说明留下哪些工程。
- 清理仅限本次新建、清单中标为可丢弃、已被验证交付取代、无引用且无用户修改的临时文件，并须符合用户当次授权。逐项核对绝对路径、归属、大小及占用后处理，不宽泛通配删除或递归清空工作区。
- 原媒体、原工程、恢复备份、旧交付、共享缓存及归属不明内容不自动删除。关闭工程不等于删除文件；项目素材箱可能仍被序列引用，不能连箱删除来节省空间。
- 只读/讨论任务不因此创建工程副本。交付前核对窗口与文件清单；未收尾的对象说明原因，空间占用/释放只报实测值。没有实际听审、画面检查或保存证据时，不以结构测试冒充完成。
